# Menu-Driven-Program-in-C-to-implement-Arithmetic-Operations

Basic Arithmetic Calculator in C
Overview

This assignment focuses on developing a menu-driven calculator in C that performs basic arithmetic operations on two user-provided numbers. The program uses the switch-case control structure to execute the selected operation based on the user's choice.

The objective is to understand the fundamentals of C programming, including operators, conditional statements, and user input/output operations.

Objectives
Understand and implement arithmetic operators in C.
Learn about relational and logical operators.
Understand the working of the switch-case statement.
Develop a menu-driven program to perform arithmetic calculations.
Handle different user choices using control flow statements.
Features
Addition of two numbers.
Subtraction of two numbers.
Multiplication of two numbers.
Division of two numbers.
Menu-based operation selection.
Default case to handle invalid menu choices.
Concepts Covered
Arithmetic Operators: +, -, *, /, %
Relational Operators: ==, !=, <, >, <=, >=
Logical Operators: &&, ||, !
Switch-Case: Used to execute a specific block of code based on the selected menu option.
Break Statement: Prevents unintended fall-through between switch cases.
Input/Output Functions: scanf() and printf().
Algorithm
Start the program.
Declare variables to store two numbers and the user's choice.
Accept two numbers from the user.
Display the menu of arithmetic operations.
Read the user's choice.
Use a switch-case statement to perform the selected operation.
Display the result.
Handle invalid choices and division by zero where applicable.
Stop the program.
Sample Output
Enter two numbers: 20 4

Choose an operation:
1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter your choice: 1
Result = 24

Learning Outcomes

By completing this assignment, I learned how to implement arithmetic operations using C, design a menu-driven program, and use the switch-case statement for decision-making. I also gained an understanding of operators and basic input validation.

Conclusion

This assignment demonstrates the implementation of a basic arithmetic calculator using the C programming language. It strengthens the understanding of operators, decision-making statements, and structured programming.

Technologies Used
